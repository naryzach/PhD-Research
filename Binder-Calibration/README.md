# Binder-Calibration

Analysis & calibration code for the de novo TIMP3-binder project. It compares the
AlphaFold-driven design predictions (the Dec-2025 Twist order) against the experimental
FCS binding results, calibrates which predicted metrics actually track binding, and
produces a multi-term selection recipe for ranking future designs.

> **Code is tracked here; every output (CSVs, figures, large files) is written to the
> gitignored `Local/` tree.** The repository stays lean — only logic is versioned.

## Scripts (run from the repo root)

| script | what it does | reads (under `Local/`) | writes (under `Local/`) |
|--------|--------------|------------------------|-------------------------|
| `analyze.py` | prediction-vs-result comparison + per-construct×target metric rollup | `AlphaFoldMetrics/`, `Aggregate_FCS_Analysis/` | `Prediction_vs_Result_Analysis/`, `Construct_Metric_Summary/` |
| `regression_sweep.py` | every AF metric × every experimental readout (heatmaps, 140 pairwise scatters) | same | `Prediction_vs_Result_Analysis/Regression_Sweep/` |
| `calibration.py` | variance decomposition, AF-metric calibration, recipe evaluation with bootstrap CI | same (+ `Generation/binding_recipe.py`) | `Calibration/` |
| `make_esmfold2_manifest.py` | builds the ESMFold2 cluster-run input manifest | `Twist_Order_Dec2025/`, `Data/.../HADDOCK_Outputs/` | `Calibration/esmfold2_inputs/` |

```bash
python Binder-Calibration/analyze.py
python Binder-Calibration/regression_sweep.py
python Binder-Calibration/calibration.py                 # AF3 / AF-server calibration (default)
python Binder-Calibration/make_esmfold2_manifest.py      # then run ESMFold2 on the cluster
python Binder-Calibration/calibration.py --esm-scores Local/Calibration/esmfold2_scores.csv
```

## The recipe lives in `Generation/`, not here
The deployable scoring function **`Generation/binding_recipe.py`** is tracked alongside
the pipeline that imports it (`select_binders_to_order.py`), because it is a runtime
module rather than analysis code. `calibration.py` imports it from there and reports how
it scores against the experimental data.

## Docs
`docs/` holds the detailed methodology + findings writeups
(`calibration.md`, `prediction_vs_result.md`, `regression_sweep.md`,
`construct_metric_summary.md`). Relative paths inside them refer to the `Local/` output
tree; run the scripts via the repo-root commands above.

## Re-fitting when new data lands
Add the new constructs to the `CONSTRUCTS` dict (in `calibration.py`, `regression_sweep.py`,
and `analyze.py`), point at the refreshed `Local/Aggregate_FCS_Analysis/`, and re-run.
Outputs overwrite in place under `Local/`. The bootstrap CI on the recipe is wide at
n=12 — treat current weights as a reasoned prior, and only let a data-fit replace them
once n is comfortably larger (see `docs/calibration.md`).

## Paper figures
The De Novo Binder paper's calibration figures are generated by
`Demonstrations/Papers/De_Novo_Binder_Generation/generate_calibration_figures.py`, which
reads the CSVs these scripts write under `Local/`.
