# PhD-Research

Code related to my PhD research (Sarmazdeh Lab, UNR SOM).

## Folders

* `3D-Print`: Converts PDB structures to STL files for 3D printing
* `AlphaFold`: Code that runs and analyzes AlphaFold predictions on binder designs
* `Binder-Calibration`: Calibrates AlphaFold-predicted metrics against experimental FCS binding results to build a design-ranking recipe
* `Daily-Brief` *(gitignored)*: Generates a daily research briefing from real pipeline data
* `Data`: Tracked reference data — crystal structures, sequence catalogs, binding-result spreadsheets
* `Demonstrations`: LaTeX papers and Slidev presentations (the `Papers/` and `SharedAssets/` subfolders are gitignored)
* `DNA Analysis`: Parses Nanodrop spectrophotometer output and plasmid/SnapGene data
* `Environment Installers`: Conda/pip environment specs and install scripts for the various pipelines
* `ESM-C Classification`: Fine-tunes ESM-C to predict per-target binding for TIMP3 loop-graft sequences (supersedes ESM2 Classification)
* `ESM2 Classification`: Earlier ESM2-embedding binder classifier notebooks (superseded, kept for reference)
* `FASTA Mod`: Utilities for generating and modifying FASTA files
* `FASTQ`: Parses FASTQ sequencing reads, finds motif hits, compares sequence similarity
* `FPLC`: Streamlit app for FPLC (chromatography) data
* `Generation`: Core generative pipeline — RFdiffusion/RFd3 backbone generation, ProteinMPNN sequence design, HADDOCK docking, binder scoring
* `Inventory-Manager`: Streamlit lab-inventory management app with admin dashboard and DB migration
* `Local` *(gitignored)*: Machine-local scratch space for generated pipeline outputs; not portable across machines
* `MetalBinder`: Pipeline/dashboard for generating and scoring metal-binding protein designs
* `MINT Classification`: Fine-tunes the MINT PPI model to predict TIMP3-variant vs. protease-target binding from paired sequences
* `Pandoc-Files`: LaTeX style files used for Pandoc document conversion
* `Protein-Analysis`: Flow cytometry (FCS) and gel-image analysis pipeline, incl. Streamlit viewer
* `Results`: Curated, tracked summary/result files (counterpart to `Local/`)
* `SLURM`: HPC job-submission scripts for cluster pipelines (log/output/credential files are gitignored)
* `Structural-Validation`: In-silico structural validation of TIMP3 constructs vs. targets via AF3/ESMFold2 + HADDOCK3, benchmarked against crystal structures
* `TIMP-Dashboard`: Interactive dashboard for exploring pipeline results and cross-docking metrics
* `Tools` *(gitignored)*: Vendored third-party repos (BindCraft, ProteinMPNN, RFdiffusion, RFdiffusion2, LigandMPNN)
